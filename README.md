# Python Quiz Game v1

A beginner Python quiz game project built using conditions, loops, score tracking, and percentage calculation.

---

# Features
- Multiple Questions
- Correct / Wrong Feedback
- Score System
- Percentage Calculation
- Final Result Grading

---

# Grading System
- 90+ → Excellent
- 70+ → Good
- 50+ → Average
- Below 50 → Keep Practicing

- User Input
